#
# ── 语法速查（已按本版代码实测校正）────────────────────────
#   [组名]          组别名，必须是该组第一行
#   关键词          标题包含即命中
#   /正则/          正则匹配（自动忽略大小写），用 | 表示"或"
#   /正则/ => 别名  给这一行指定显示名
#   +词             必须词：本组内所有 + 词都命中才算匹配（AND，可用正则）
#   @数字           本组最多显示条数
#
# ⚠️ 两个与官方文档不符、但已在本版代码实测确认的行为：
#   1. [GLOBAL_FILTER] 区**不支持正则**。代码直接把整行当普通字符串做包含比对，
#      写 /a|b/ 会去匹配字面量"/a|b/"，永不命中。所以本区只能一个词一行。
#   2. 词组里的 !排除词 **不是"仅限当前词组"，而是汇总后对全库生效**
#      （frequency.py 把它们 append 进同一个 filter_words 列表，
#       并在词组匹配之前统一拦截）。因此排除词必须极度克制，
#       像"降价""优惠""明星""二手"这种会误杀"茅台降价""二手房""AI明星企业"。
#      → 结论：排除词统一放进 [GLOBAL_FILTER]，只收录对任何主题都无价值的词。
#
# ── 本次改造要点（相对改造前）──────────────────────────────
#   1. 新增整个投资财经维度：宏观利率 / 权益市场 / 债汇 / 大宗商品 / 政策监管
#   2. 原「国家与地区」组只有"中国""美国""日本"等裸词，会命中几乎所有新闻，
#      现改为 @3 条数封顶，仅作背景参考
#   3. 原公司组里的泛产品词（微信/QQ/Windows/安卓/iPhone/iPad）会持续招回
#      数码评测，现改为只保留公司 / 人物 / 核心技术词
#   4. AI 组补上"大模型 / AIGC / LLM / 智能体 / 算力"等中文高频词（原缺失）
#   5. 修正"理想"这类既是大厂名又是常用词的误匹配（改为"理想汽车"）
# ═══════════════════════════════════════════════════════════════
